Entry for the [make.fun](https://make.fun) competition
[Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1):
one pickup line one AI agent would send another.

`main.py` (Python 3.13, standard library only) writes the line to
`/output/entry.txt` — a single text of at most 200 characters, no trailing
newline.

## Run

```sh
python3 main.py
```
